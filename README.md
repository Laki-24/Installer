\# AudioArchiver



A Python desktop application for managing and processing media that I am authorized to download.



\## Current Features



\- Extract unique URLs from a YouTube playlist

\- Prevent duplicate URLs

\- Append newly discovered URLs

\- Audio downloading

\- MP3 and MP4 output with embedded metadata and artwork

\- Windows desktop application



\## Planned Features



\- Individual video URL support

\- MP3 output

\- MP4 output

\- Metadata

\- Cover art

\- Optional lyrics

\- Download history

\- Resume support

\- Minimal GUI



\## Technologies



\- Python

\- yt-dlp

\- FFmpeg

\- Tkinter

\- PyInstaller

\- Mutagen (MP3/MP4 metadata embedding)

## Install

```powershell
python -m pip install -r requirements.txt
python app.py
```
